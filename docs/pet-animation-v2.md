## 动作与节奏

| 类别 | 素材 | 原始时长 | 画面重点 |
| --- | --- | --- | --- |
| 敲击 | `tap` / `typing` | 300 / 480 ms | 单次轻压回弹；连续敲击左右手交替 |
| 庆祝 | `celebrate` / `celebrate_big` | 1400 / 2300 ms | 一次小跳；两次小跳后得意停顿 |
| 拖动 | `pickup` / `struggle` / `release` | 150 / 720 / 300 ms | 提起睁眼、挥手踢腿、落稳回弹 |
| 随机待机 | `look` / `stretch` / `play` | 2200 / 2400 / 2200 ms | 左右张望、举手舒展、摆手踢脚 |
| 休息 | `doze` / `sleep` / `wake` | 2800 / 4000 / 260 ms | 点头、闭眼慢呼吸、睁眼回正 |
| 悬停 | `hover` / `hover_hold` / `hover_leave` | 660 / 2400 / 200 ms | 抬头注视、轻呼吸、收回目光 |
| 注视方向 | `hover_left` / `hover_up` / `hover_down` | 各 2400 ms | 一像素方向变化；`hover_hold` 为向右 |
| 单击 | `click` | 650 ms | 惊讶、轻侧摆、摸脸与笑眼 |

每个摆放位置包含 18 段素材，其中 `rest` 是原有待机第一帧参考。
五种摆放位置共 90 段，加上 3 段拖动素材，共 93 段、526 个帧格；其中 5 段是待机参考，
其余 88 段为本轮制作。自由位置的单次动作通常以与原程序一致的待机帧收尾。
悬停招呼接注视，拖动提起接挣扎，醒来按实际事件衔接敲击、悬停、单击或庆祝。

## 贴边适配

| 位置 | 保持不动 | 动作方式 |
| --- | --- | --- |
| 自由摆放 | 固定画布；普通动作脚底稳定 | 双手、双脚和机身；庆祝允许短暂离地 |
| 左右边 | 扶边手接触位置 | 上半身轻探、眼神、空闲手；下半身仍藏在屏幕外 |
| 顶边 | 两只手的抓握位置 | 身体小幅提起、侧摆和双腿活动；伸展时腿部舒展 |
| 底边 | 两只手的下缘接触位置 | 抬头、机身小幅起伏及指端变化 |

侧身抬手绘制在头部后方，避免遮挡双眼；左右的非方向性动作保持镜像。
注视方向以屏幕左右为准，右侧版本单独反转局部眼神偏移。
所有贴边版本独立绘制，没有通过切换成完整站立角色来代替动作。
拖动使用完整角色；本轮 `release` 只用于自由位置，不作为四边吸附过渡素材。

## 素材与生成

- [透明图集](pet-animation-v2/atlas.png)：768 × 5952，12 列、93 行，每格 64 × 64。
- [配置](pet-animation-v2/atlas.json)：逐帧位置、时长、包围框、锚点、接触点、循环和后续动作。
- `review_schema_version: 1` 是独立的评审格式，运行时现在使用 `schema_version: 2`。
- 评审 JSON 的 `status: awaiting-visual-approval`、`runtime_integration: false` 保留制稿时状态，
  不用于判断当前程序进度；运行图集标记为 `status: runtime`。
- `pose.behavior` 区分摆放姿态和行为；运行图集含原有 8 段与新增 88 段，共 96 段、571 帧，
  768 × 6144 像素。5 段 `rest` 参考不重复收录，直接衔接原有待机或贴边循环。
- 使用最近邻缩放、原有色板与二值透明度；未使用的图集格为透明。
- 定位仍使用固定画布和锚点，不能按每帧包围框重新居中。
- 逐帧对照：`contact-free.png`、`contact-left.png`、`contact-right.png`、
  `contact-top.png`、`contact-bottom.png`、`contact-drag.png`。
- `review-data.js` 由配置和 PNG 自动生成，并内嵌预览图集，便于离线打开。

图集生成复用现有 QPainter 像素制图工具；GIF 使用制图环境的 Pillow，不新增应用依赖。

```powershell
.\.venv\Scripts\python.exe tools\build_pet_motion_review.py
# 使用已有 Pillow 的制图环境执行：
python tools\render_pet_motion_review.py
```

第二条命令中的 `python` 必须指向已有 Pillow 的制图环境。本轮使用 Codex 随附 Python，
未向项目 `.venv` 或全局 Python 安装 Pillow。两个脚本默认只输出 `docs/pet-animation-v2/`。
预览页 `index.html` 为独立维护的文件，重新生成素材不会覆盖页面。
运行图集通过以下命令重新生成；原 `build_pet_atlas.py` 入口也输出完整运行图集：

```powershell
.\.venv\Scripts\python.exe tools\build_pet_runtime.py
```

EXE 资源路径保持不变，仍收集运行图集的 PNG / JSON，评审目录不纳入发布资源。
源码快照会收集制图脚本，重建运行素材不依赖评审目录或 Pillow。

## 运行规则

- 接纳的新物理按下触发敲击；相邻敲击间隔不超过 350 ms 视为连续输入，先完成已有单次动作，
  再循环敲击；停止输入约 650 ms 后结束。高频按键延长有效期，不逐键重启动画。
- 复用每日里程碑及其开关，新的整千触发小庆祝，整万触发大庆祝；不依赖 Windows 横幅是否显示。
  启动基线、跨天、关闭提醒和覆盖导入今天都遵循原计数规则，不补庆祝历史阈值。
- 拖动优先于庆祝，庆祝优先于单击、悬停、敲击和随机动作。拖动中只保留最高的待播阈值，
  有效期 5 秒；隐藏、会话暂停、菜单打开会清空待播状态。
- 鼠标停留约 150 ms 后招呼，随后按方向注视；单击等待系统双击间隔并有 800 ms 冷却。
  双击立即打开主界面并取消待播单击，超过系统拖动距离后进入提起和挣扎。
- 无键盘或鼠标互动至少 20 秒后可随机张望、伸展或玩耍，随机间隔 20–40 秒，不连续重复；
  约 90 秒打瞌睡，约 180 秒浅睡。互动时先播放 260 ms 醒来动作。
- 复用宠物单次定时器，按帧时长及最近交互截止时间唤醒；原生按键回调只合并少量状态。
  所有图像与透明区域在初始化时加载，播放时不读盘，不记录按键序列，不改变统计或保存频率。
  四边始终使用各自接触线定位，透明命中区域随当前帧更新。
