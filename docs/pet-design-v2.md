# 敲敲桌面宠物：深色与探身修订 v2

状态：2026-11-11 用户暂定采用本版形象；第一版动作素材已生成，尚未接入程序。
动作文件、播放节奏与接触点约定见 [动作图集 v1](pet-animation-v1.md)。
本版替代 v1 的角色配色和左右偷看姿态，其余交互方向沿用已讨论的方案。

## 本轮调整

- 左右贴边时，上半身向屏幕内部倾斜约 34°，上部伸出更多，下部逐渐藏回边缘。
- 去掉左右偷看时露出的脚，保留两只完整眼睛及一只扶边的手。
- 重画贴边时的面板位置、侧面透视和弯曲前臂；手的抓握位置不随身体倾斜。
- 主体由浅白改为深灰紫，顶面、侧面、手脚同步调整；薄荷绿继续作为表情重点。

## 配色

| 部位 | 颜色 | 用法 |
| --- | --- | --- |
| 外轮廓 | `#0D0C14` | 像素硬边，在浅色背景上保持轮廓 |
| 主体 | `#443A53` | 深灰紫机身和手部 |
| 顶面 | `#655971` | 与主体保持明暗差，表现键帽厚度 |
| 侧面 / 阴影 | `#54465F` / `#2C283B` | 两档硬边明暗 |
| 棱边 | `#8D7C9E` | 窄幅提亮，帮助暗色桌面下辨识轮廓 |
| 面板 | `#191621` | 比机身更深，突出眼睛 |
| 眼睛 / 眼部高光 | `#97E4C2` / `#CEF2DF` | 小面积薄荷绿，不使用光晕 |
| 手脚细节 | `#568F80` | 降低亮度，避免抢过眼睛 |
| 脸颊和腕部点缀 | `#C7849C` | 比 v1 更克制的粉色 |

以上是角色预览配色，不改变应用的共享主题、图标或窗口样式。
角色不再使用大面积白色；棱边是实色像素，不是柔光或外发光。

## 左右探身

以左侧为例：下半身留在屏幕外，上半身向右倾斜；越靠近身体下部，伸入桌面的面积越少。
两只眼睛面向桌面内部，近侧前臂弯回边缘，手贴在边缘上；脚不在可见区域出现。
右侧姿态按同一体量反向处理。

本版不再以“整个人竖直露出 45%–55%”作为目标，而以倾斜、上身先探出、下部隐藏、
眼睛完整及扶边接触自然为判断标准。倾斜约 34° 是当前预览取值，可在看图后调整。
未来轻微探出和缩回动作需要固定手的接触点，不能把整张图平移后让手离开边缘。

## 其他姿态与尺寸

沿用自由待机、轻呼吸、眨眼、拖动提起、底边趴伏及顶边悬挂。
本轮同时修正了预览中呼吸高点的脚底基线，以及提起姿态中身体与腿部之间的断开。
底边像素保留在任务栏上方，顶边脸部完整可见。

- 逻辑画布：64 × 64。
- 八姿态设计板：4 倍展示。
- 左右细节主图：5 倍展示。
- 桌面尺寸和深浅背景样例：2 倍展示，画布为 128 × 128。

输出 PNG 的像素尺寸用于评审；聊天中的自动缩放或系统 DPI 不保证按原像素呈现。
本页三张预览仍是静态关键姿态；另行生成的动作图集也尚未接入宠物窗口。
